** install

** Preparation
prepare ~/.config/xmonad

prepare initial config file
file:~/.config/xmonad/xmonad.hs

#+begin_src haskell
  import XMonad

  main :: IO ()
  main = xmonad $ def
    { modMask = mod4Mask -- rebind Mod to Super key
    }
#+end_src

Download XMonad sources
#+begin_example
cd ~/.config/xmonad/
git clone https://github.com/xmonad/xmonad
git clone https://github.com/xmonad/xmonad-contrib
#+end_example

** Build using stack
Because I have ghcup, I have stack already installed.

*** Create a New Project
#+begin_example
cd ~/.config/xmonad/
stack init
#+end_example

That creates stack.yaml file

compile
#+begin_example
stack install
stack build
#+end_example

the xmonad is built in folder /home/jacek/.local/bin/
add it to bashrc if needed

** Make XMonad your window manager
make file:~/.xsession read
#+begin_example
exec monad
#+end_example


Now login into blank X session gives me the compiled xmonad as window manager
