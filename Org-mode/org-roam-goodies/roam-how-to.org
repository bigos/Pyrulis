* Roam How To

This folder is for folders with org-roam notes.

** switch project script
This switches the current symbolic link to point to the right roam.

#+begin_example
$ pwd
/home/jacek/Documents/Roams

$ ./switch_project ./githubkasten
Switching the current Roam to ./githubkasten

'./current' -> './githubkasten'
#+end_example

** nice alternative to switch_project
This does not require use of the symbolic link, but uses internal Emacs setting.

[[file:~/.emacs.d/personal/organised.el::defun override-current-org-roam-my-folder (path]]

#+begin_src emacs-lisp
  (override-current-org-roam-my-folder "/tmp/scratch/org-roam/")
#+end_src


** creating new roam alternative
#+begin_src emacs-lisp
  (let ((new-current "/tmp/scratch/org-roam/"))
    (make-directory new-current :parents)
    (override-current-org-roam-my-folder new-current))
#+end_src

** recommended .gitignore
If we need to track the notes with git, we can use a .gitignore like that:
#+begin_example
# gitignore for org roam notes

# ignore database
org-roam/org-roam.db
org-roam.db

# ignore accidentally exported html files
org-roam/*.html
#+end_example
